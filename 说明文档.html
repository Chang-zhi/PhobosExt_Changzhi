PhobosExt 扩展 DLL

为《红色警戒2：尤里的复仇》扩展游戏功能的 DLL，面向任务与地图作者，可自由用于任务包与模组。
作者 Chang_zhi。

仅部分功能依赖 Phobos：不安装 Phobos 也可独立使用，推荐与 Phobos 一同使用。

左侧导航栏查看各功能详情；顶部搜索框可直接搜功能名、编号或键名。

兼容性

  • 需游戏版本 YR 1.001。
  • 不依赖 Ares 或 Phobos，可单独使用；与 Ares、Phobos 共存不会冲突。
  • 依赖 Phobos 的功能：触发行为 653、654（需 Phobos v0.5-alpha 及以上）。
    → 查看对应的触发行为（653／654）

已知问题

  1. 使用 Temporal=yes + Temporal.Exclusive=yes 的武器会改变单位的选敌逻辑，可能出现异常。
  2. LegalTargetWhenAIOwner=no 的 AI 单位会改变其他单位的选敌逻辑，可能出现异常。
  3. 基地节点跨所属方判定开启后：与触发行为 30（自动建设基地）不兼容，且不要让 AI 造围墙。
    → 查看基地节点跨所属方判定

1. 超时空武器扩展

给超时空武器（Temporal=yes 的弹头）增加两种能力：同一目标只被一个武器锁定、攻击时连周围单位一起冻结。

[WarheadType]
; 互斥锁定
Temporal.Exclusive=              ; boolean - 同一目标只被一个单位锁定 - (默认 false)
; 范围冻结
TemporalAOE.Enable=              ; boolean - 启用范围冻结 - (默认 false)
TemporalAOE.CellSpread=          ; double - 冻结范围半径（格） - (默认 2.0)
TemporalAOE.SecondaryWeight=     ; double - 副目标冻结时间权重，可填负值 - (默认 1.0)
TemporalAOE.AffectsAllies=       ; boolean - 是否连友军一起冻结 - (默认 false)

1.1 互斥锁定：Temporal.Exclusive

启用后，同一目标只会被一个单位锁定：正被其他单位超时空冻结的目标不会被选为攻击对象，对方用的是不是互斥武器都一样。
若多个单位已同时锁定同一目标，只保留一个，其余自动放弃。

注意
  • 只在弹头同时写了 Temporal=yes 与 Temporal.Exclusive=yes 时生效。
  • 限制是单向的：互斥武器不能攻击正被其他单位冻结的目标；而普通超时空武器不受约束，仍可攻击已被互斥武器锁定的目标。
  • 该机制会改变单位的选敌逻辑（见首页「已知问题」）。

1.2 范围冻结：TemporalAOE.Enable

抹除倒计时：
抹除主目标自身需要 10 × 生命值上限 ÷ 武器 Damage 帧，
每个副目标再增加 10 × 生命值上限 × SecondaryWeight ÷ 武器 Damage 帧。
副目标越多、生命值上限越高，抹除越慢；SecondaryWeight 填负值则更快。

例：Damage=100、副目标生命值上限 200、SecondaryWeight=1.0 → 每个副目标多撑 20 帧。

注意
  • 同一个副目标只累加一次；离开范围/死亡后解除冻结，但已累加的时间不会扣回，这是为了防止主目标被瞬间抹除。
  • 主目标与副目标都被该单位独占：其他超时空武器无法对其开火，所以不会出现多个单位给同一目标叠加时间的情况(为了防止bug)。
  • 正在使用超时空武器的单位不会被选为副目标，避免多个超时空武器互相冻结。

2. 自动游猎

[TechnoType]
AutoHunt=                        ; boolean - AI 单位自动进入游猎状态 - (默认 false)

该类型的所有 AI 单位自动进入 Hunt 状态，主动搜索并攻击敌方目标。

注意
  • 仅对 AI 控制的单位生效，人类玩家控制的单位不受影响。
  • 已在作战小队中的单位不生效。
  • 位于载具内的单位不生效，离开载具后自动生效。
  • 单位处于部署状态时会先解除部署。
  • 当前攻击目标是地面（强制攻击地面）时，目标会被清除并重新索敌。
  • 目标所在格不可抵达时，本次不执行索敌。
  • 该类型单位会被强制设为不可招募。

3. AI 单位能否被选为攻击目标

[TechnoType]
LegalTargetWhenAIOwner=          ; boolean - AI 控制时能否被其他单位选为攻击目标 - (默认 true)

设为 no 后，该类型在由 AI 控制时不会被其他单位选为普通武器的攻击目标。

注意
  • 不影响人类玩家控制的该类型单位。
  • 仍可被 C4 爆破、受伤害反馈等非伤害手段命中。

4. 基地节点跨所属方判定

[Country House]
BaseNodeCrossOwners=             ; boolean - AI 评估基地节点时是否计入所有所属方建筑 - (默认 false)

启用后，AI 判断某个基地节点是否已经建好时，会把场上所有所属方的建筑都算进来，而不是只看自己的建筑。

典型用途：让 AI 给玩家造建筑——玩家拿到 AI 的建筑后，AI 认为该节点已完成，不再重建。

节点由本 DLL 按记录顺序控制建造，不会出现原版那种节点自动移位。

注意
  • 与触发行为 30（自动建设基地）不兼容：本功能接管了 AI 的节点建造顺序，开启行为 30 也不会更换建筑位置。
  • 开启后不要让 AI 造围墙，会导致建造卡住。
  • 触发行为 560 的「立即建造」参数在此模式下会把节点插到队列最前面，AI 下一帧优先建造它。
  • 触发行为 560／561／562 增删节点时，本功能记录的数据会同步更新。

5. 混乱机制扩展

5.1 混乱恢复后清除目标

[General]
BerzerkRestoreClearTarget=       ; boolean - 混乱恢复后是否清除当前攻击目标 - (默认 false)

启用后，单位从混乱状态恢复时会清除当前攻击目标、停止移动并转入 Guard 状态，避免恢复后乱跑。

5.2 弹头缩减混乱时间

[WarheadType]
BerserkReduce=                   ; integer - 缩短混乱时间的帧数，负值则延长 - (默认 0)

单位被带此标签的弹头命中时（无论是否造成伤害），混乱时间减少对应帧数。

  • 正值 = 缩短混乱时间；负值 = 延长混乱时间。
  • 减到 0 以下时立即解除混乱，并清除攻击目标、进入 Guard 状态。

MaxWidth最大宽度（像素），超出该宽度的文字自动换行；填 0 或负数按 250 处理。
BackgroundOpacity黑色背景的不透明度，值越大背景越深：0=全透明，100=全黑。
Color文字与边框颜色。鼠标悬停时加亮，选中时变红。
Duration自动消失的帧数。-1=一直显示，需用触发行为清除；归零时若玩家没点过按钮，会触发「超时未选」事件。
Title／Description标题显示在最上方，描述显示在标题下、按钮上；不填则不显示。
Title.Center标题是否水平居中，默认左对齐。
Button.Count按钮数量。有几个按钮就要写几个 Button.TextN。
Button.Layout按钮排列：Horizontal=横向，一行放不下自动折行；Vertical=纵向单列。
Button.ModeNormal=点击后选择框立即消失并清理；Bounce=点击后回弹，可反复点击（建议配合 Duration=-1）。
Button.Width固定宽度（像素），文字自动换行；0=按最长按钮文字自适应。
Button.Height固定高度（像素），超出部分不显示；0=按文字行数自适应。
Button.TextN第 N 个按钮的文字，序号从 1 连续写到 Button.Count；中间跳过会显示空白按钮，超出数量的不会被读取。

7. 单人任务 Tab 打开任务简报

原版单人任务中 Tab 无法重新打开任务简报，本项用于放开该限制。

[General]
AllowTabBriefingInSinglePlayer=  ; boolean - 单人任务中能否用 Tab 打开任务简报 - (默认 false)

设为 yes 后，单人任务中可随时按 Tab 打开任务简报；简报内容可用触发行为 664 动态修改。

8. SmartVHPScan 智能火力分配

名字沿用VHPScan仅为习惯，其独立于原版逻辑，实现更智能、可操作性更强的火力分配。

[TechnoType]
SmartVHPScan=                    ; 枚举字符串 - 索敌模式 None/LowHealth/FullHealth/Count - (默认 None)
SmartVHPScan.Count=              ; integer - 同一目标最多几个单位同时打 - (默认 1)
SmartVHPScan.Bias=               ; double - 偏好强度，越大越执着 - (默认 2.0)
SmartVHPScan.UnknownFactor=      ; double - 血量未知目标的分值倍数 - (默认 1.0)
SmartVHPScan.ExcludeFraction=    ; double - 低于该血量比例的目标不打，0=关闭 - (默认 0.0)
SmartVHPScan.Damage=             ; integer - 等效伤害，0=用武器自身 Damage - (默认 0)
SmartVHPScan.Overflow=           ; double - 允许多浪费多少火力，0=够杀就停 - (默认 0.25)
SmartVHPScan.SwitchThreshold=    ; double - 换目标的门槛倍数，越大越不易改目标 - (默认 1.25)
SmartVHPScan.IncludeInflight=    ; boolean - 飞行中的弹药算不算已投入火力 - (默认 true)
注意
  • 与原版互斥：单位自身的 VHPScan 为 Normal 或 Strong 时，本功能不生效。
  • Damage 用于估算「几发能打死」。心控、超时空冻结这类 Damage 有特殊含义的武器，建议手动填一个等效值。

索敌模式

值说明
None不启用。
LowHealth残血优先，血越少越先打。
FullHealth满血优先，血越多越先打。
Count不看血量，只限制同一目标的攻击人数。

属性说明

属性适用模式说明
CountCount同一目标同时开火的上限，盟友的单位也计入；填 0 或负数按 1 处理。
BiasLowHealth／FullHealth偏好强度，越大越执着于残血／满血目标。
UnknownFactorLowHealth／FullHealth刚出现、血量未知的目标的分值倍数：1.0=一视同仁，调低靠后，调高靠前。
ExcludeFraction全部血量低于该比例的目标不再攻击，0=关闭（如 0.05 表示剩 5% 血以下不打）；血量未知的目标不受影响。
Damage全部等效伤害，0=使用武器自身的 Damage。
Overflow全部允许多浪费的火力比例：0=够杀就停，0.5=最多多打一半。一般取 0 ~ 0.5。
SwitchThreshold全部换目标门槛：新目标要好上这么多倍才换，避免来回改目标；1.0=只要更好就立刻换。
IncludeInflight全部已发射、尚未落地的弹药是否算作已投入火力。

示例

; 超时空兵：一个目标只派一个人
[CLEG]
SmartVHPScan=Count
SmartVHPScan.Count=1

; 尤里：优先控制满血目标
[YURI]
SmartVHPScan=FullHealth
SmartVHPScan.Damage=999

; 天启坦克：优先处理满血目标
[APOC]
SmartVHPScan=FullHealth

1. 自动装载

选中空载具后按快捷键，自动招募附近单位上车。招募半径可自定义：

[General]
Command.RecruitRange=            ; double - 自动装载的招募半径 - (默认 10.0)

招募顺序（三轮依次进行）：

  1. 选中的单位优先：当前选中的非载具单位不限距离，全部就近分配到各载具。
  2. 附近单位补位：在 Command.RecruitRange 范围内，招满剩余座位。
  3. 载具互上：前两轮没招到人的载具，可以把自己当作乘客登上其他载具。

分配规则：容量小的载具先挑（按 SizeLimit 从小到大），同容量的轮流分配，一组装满才轮到下一组；
距离相同时优先选体积更小的单位；
满员或没匹配到人的载具仍可作为乘客上车。

自动跳过：飞行器、已在天上的单位、部署后解除部署会飞行的单位、正在前往其他载具途中的单位。

部署状态的单位会先解除部署再上车；
与载具同格的单位会先散开，避免互相阻挡。

1.跟随单位时视野移动行为失效

现象
